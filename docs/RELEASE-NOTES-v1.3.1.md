# انباردار ۱.۳.۱

مدیریت آفلاین موجودی انبار با رابط فارسی، ساخته شده توسط **amiraidev**.

## امکانات این نسخه

- مدیریت کالا، دسته‌بندی، چند انبار و طرف حساب‌ها.
- ثبت ورود، خروج، انتقال، برگشت کالا، اصلاح موجودی و انبارگردانی.
- گزارش گردش و موجودی با تاریخ شمسی و خروجی Excel، CSV و PDF.
- تهیه و بازیابی پشتیبان JSON.
- حالت روشن و تاریک، قفل چهاررقمی و راهنمای شروع.

## نصب

فایل دارای پسوند `.apk` را از بخش **Assets** همین Release دریافت و روی گوشی اندرویدی نصب کنید. برای اجرای نسخهٔ نصب‌شده به Expo Go یا کامپیوتر نیاز ندارید.

پیش از به‌روزرسانی، از تنظیمات برنامه پشتیبان JSON بگیرید. برای حفظ اطلاعات، نسخهٔ جدید را روی نسخهٔ قبلی نصب کنید.

## اطلاعات محلی

اطلاعات روی دستگاه ذخیره می‌شود. همگام‌سازی زنده میان چند گوشی در این نسخه وجود ندارد. قفل چهاررقمی دسترسی به برنامه را محدود می‌کند؛ فایل پشتیبان را رمزگذاری نمی‌کند.

برای گزارش اشکال، مدل گوشی، نسخهٔ اندروید، نسخهٔ برنامه و مراحل بروز مشکل را در بخش Issues بنویسید.
